# GitHub Trending 周刊

每日自动抓取 GitHub Trending 周榜，筛选约 12 个最热仓库，生成中文精选网页。

## 自动更新

- GitHub Actions 每天 09:45 (北京时间) 自动运行
- 抓取 → 筛选 → 生成 HTML → 提交 → 部署到 GitHub Pages
- 完全不依赖本地电脑，关机也照常更新

## 手动触发

在仓库 Actions 页面 → "GitHub Trending Weekly Update" → Run workflow
